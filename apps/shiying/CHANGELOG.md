# 更新记录

## 拾影 0.1.0

首个 Windows x64 免安装发布版本。

- 粘贴网页网址或分享文字，查找受支持的视频与页面嵌入资源。
- 多视频选择、实际可用清晰度选择、统一保存为 H.264 / AAC MP4。
- 下载进度、实时速度、剩余时间、失败原因和重试；支持可核对资源的进度保留。
- 下载历史、队列恢复、文件命名、重名保护及未完成素材管理。
- 主动读取自己的浏览器登录状态或导入 Cookies，提供简体中文操作指引。
- 环境检查、本机数据管理和解析引擎更新与恢复入口。
- 包含 Python、Qt、FFmpeg、ffprobe 和 Deno；无需另外安装开发环境。
- 修复打包误带入其他工具 ICU DLL 导致的界面启动失败。
- 更新构建时先验证成品，保留旧版和本机数据；补充启动诊断。

验证：296 项源码测试、5 项更新保留数据测试通过；真实 EXE 启动、四格式本地资源下载与 MP4 完整解码、后台 worker 完整 MP4 验证通过。未验证全部外站或另一台 Windows 10 电脑。

本版没有 Windows 代码签名证书，程序未签名，部分电脑可能提示或拦截；详见[下载与启动说明](DOWNLOAD.md)。
