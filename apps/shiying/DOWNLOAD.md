# 拾影 · 下载与启动

## 我只想使用应用

1. 打开[GitHub Releases](https://github.com/sjy1107/GPTcreateWorld/releases)，找到“拾影 0.1.0”。
2. 展开 **Assets**，下载 **Shiying-0.1.0-Windows-x64-Portable.zip**。
3. 将 ZIP **完整解压**，打开解压得到的 **Shiying** 文件夹。
4. 双击最外层的 **拾影.exe**。粘贴网址，点击“查找视频”，勾选视频、选择清晰度和保存位置，再点击下载。

适用于 Windows 10/11 的 64 位电脑；已经包含 Python、界面库、FFmpeg、ffprobe 和 Deno，不需要单独安装。当前实际验收在本机 Windows 上完成，没有保证所有 Windows 版本和电脑都已通过测试。

请保留 `_internal`、`tools`、`licenses` 和 `portable.flag`。不要只复制 EXE，也不要直接在压缩包中启动。`data` 在首次运行后保存设置和记录，`downloads` 是默认视频保存位置。按 **F1** 可查看内置使用指南。

## 没有代码签名证书会怎样？

目前开发者没有受信任的 Windows 代码签名证书，本版 EXE **未签名**。因此，Windows 可能显示“未知发布者”，SmartScreen 或智能应用控制也可能阻止运行。代码签名用于验证发布者身份；它不是使用者需要补装的 Python 或视频组件。

请只从这个仓库的 Releases 下载，核对文件名、版本和 SHA-256。随附的 `.sha256` 文件用于核对压缩包是否一致，**不能代替代码签名或系统安全检查**。若系统阻止启动，请保留提示和错误代码，向项目反馈；本项目不要求关闭系统防护或修改安全策略，也不会自动更改这些设置。

## 哪个下载是源码？

| 文件或入口 | 适合谁 | 如何使用 |
| --- | --- | --- |
| `Shiying-0.1.0-Windows-x64-Portable.zip` | 直接使用应用 | 完整解压，双击“拾影.exe” |
| `Shiying-0.1.0-Source-and-Build.zip` | 查看源码或重新构建的人 | 包含应用源码、打包脚本、依赖版本和构建记录；按其中的说明准备环境 |
| GitHub 自动提供的 `Source code (zip/tar.gz)` | 开发者 | 是整个作品集仓库在该标签下的源码，需要自行安装依赖 |
| 仓库 `apps/shiying` | 开发者 | 拾影应用的源码、测试和使用文档 |

## 保留记录升级

关闭软件，备份旧版的 `data`。把新版完整解压到新文件夹，再复制旧 `data`；若使用默认 `downloads`，可一并复制，或在软件中选择原来的视频目录。保留新版自己的 `_internal` 和 `tools`，不要运行中覆盖程序组件。不要把自己的 `data`、视频或 Cookies 重新上传分享。

## 使用范围

软件只输出 MP4。可用画质取决于网站提供的资源；需要登录的视频仍需使用自己的有效登录状态，读取 Cookies 不会增加账号权限。不保证所有网站可用，不绕过 VIP、付费或 DRM 限制。请只保存自己有权下载的内容。
